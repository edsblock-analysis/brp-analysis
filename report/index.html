Overview

BRP-World's international site is a custom Adobe AEM Sites (WCM Core Components) implementation. The DOM confirms this unambiguously: cmp-hero-block, cmp-teaser, cmp-carousel, cmp-accordion, aem-Grid responsive grid columns, and clientlib bundles (/etc.clientlibs/nextgen/…). Crucially, 83% of pages render from a single master template (brp-world-content-template, 1,156 pages), signalling a highly systematized, component-driven site that maps very well onto EDS's block model.

Migration Complexity: MEDIUM–HIGH

The block palette is small and highly reusable (a dozen core components cover >95% of pages), which is favourable. Complexity is driven by: (a) the BYO product configurator (183 pages) which embeds a third-party application (sitebuild-*.brp.zlthunder.net) via iframe — not natively re-authorable in EDS; (b) heavy localization — up to 68 hreflang locales per page; (c) five distinct brands (Ski-Doo, Sea-Doo, Can-Am Off-Road, Can-Am On-Road, Lynx) requiring theming; and (d) rich, carousel-dense product/lineup pages.

Major Findings

  • Component-driven, high reuse. 5 blocks (Teaser, Image, Breadcrumb, Hero, Carousel) appear on 380–1,144 pages each — a shared block library will cover the vast majority of the site.
  • Analytics/monitoring already EDS-friendly. The site already runs Adobe Helix RUM (native to EDS) plus GTM, Dynatrace and Typekit on 100% of pages.
  • Configurator is the key risk. 183 "Customise-Your-Own" pages are iframe-embedded external apps — migration = re-embed, not rebuild, but requires product-team coordination.
  • Content hygiene gaps. 779 pages lack a meta description and 402 pages expose multiple H1s (hero carousels) — an SEO clean-up opportunity during migration.
  • No traditional CMS forms at scale. Only 2 pages contain native <form> elements; lead-gen is light.

Recommendations

  • Adopt a shared EDS block library of ~22 blocks; theme per brand via CSS custom properties.
  • Automate import of the 1,156 master-template pages via the bulk importer; hand-treat configurator, locator and forms.
  • Keep Scene7/DAM asset URLs initially; optimize to EDS image handling in a fast-follow.
  • Treat the BYO configurator as an embed block and align with the product/e-commerce team early.
  • Fold the SEO clean-up (meta descriptions, H1 discipline) into the migration to bank an SEO win.
